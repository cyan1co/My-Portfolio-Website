# My Portfolio Website

A modern responsive portfolio website built with React, Vite, Tailwind CSS, and Lucide React.

## About

This portfolio showcases my skills, projects, education, and career interests in Frontend Development and Data Analytics.

The website was designed and developed to demonstrate responsive web design, React development, and modern UI practices.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Modern React component architecture
* Interactive project showcase
* Skills section with categorized technologies
* Education and academic background
* Downloadable Frontend Developer CV
* Downloadable Data Analytics CV
* Contact section with professional links
* Back-to-top button
* Smooth scrolling navigation

## Technologies Used

* React
* Vite
* Tailwind CSS
* Lucide React
* JavaScript
* HTML5
* CSS3
